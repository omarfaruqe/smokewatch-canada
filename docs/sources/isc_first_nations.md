# Source: Indigenous Services Canada, First Nation locations

- **Publisher:** Indigenous Services Canada (Open Government Portal)
- **Licence:** Open Government Licence – Canada
- **URL:** `https://data.sac-isc.gc.ca/geomatics/rest/directories/arcgisoutput/DonneesOuvertes_OpenData/Premiere_Nation_First_Nation/Premiere_Nation_First_Nation_CSV.zip`
- **Bronze:** `isc/first_nations/Premiere_Nation_First_Nation_CSV.zip` (static, sha256 manifest)
- **Raw table:** `raw.isc_first_nations` (`band_number`, `band_name`, `longitude`, `latitude`, text)

## Profile (November 2026 pull)

- 637 First Nations, one point each, UTF-8 with BOM; coordinates in NAD83(CSRS)
- Names containing characters such as ʔ appear as `?` in the published file
- The point is usually the band administrative office. A band's reserves can be far from it,
  so the nearest AQHI location is an approximate indicator for the community.
- Some reserves were incompletely enumerated in the 2021 Census, which also affects the
  Census Profile counts in those areas.
